Mode

One card per page. Each line inside is an object you can style on its own. Drag the handle (⠿) to reorder or move it to another page, or use the arrows. Merge joins an object with the one below it; Split cuts at your cursor. To highlight just some words, select them in the text box and press Highlight words (they show as ==like this==).

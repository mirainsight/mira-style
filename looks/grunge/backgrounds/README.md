# Backgrounds

The Grunge look's photo backgrounds are **not bundled in this public repo yet**, until where each photo came from is confirmed.

The look still works without them: the generated backgrounds (Glow, Streaks, Paper, Flat) need no files, and a photo background with a missing file falls back to the palette's base colour.

To use the photo backgrounds in `example/`, drop your own JPGs in this folder with these names:

| File | Background | Size |
| --- | --- | --- |
| `moon.jpg` | Your photo | 1080 x 1928 (tall: it drifts up 24px on each slide) |
| `wind2-soft.jpg` | Path (soft) | 1080 x 1350 |
| `wind2-faint.jpg` | Path (faint) | 1080 x 1350 |
| `hand-soft.jpg` | Hand (soft) | 1080 x 1350 |
| `hand-faint.jpg` | Hand (faint) | 1080 x 1350 |

The originals are blurred, glowing orange shapes (a winding path, an open hand) on a deep red-brown, plus a blurred dusk photo with a small moon. Any soft, out-of-focus image in the palette's colours works.

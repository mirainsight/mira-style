# Backgrounds

Mira's own photo backgrounds for the Grunge look. Like the doodles in other looks, they are shared under [CC BY-NC 4.0](../../../LICENSE-ART.md): use them with credit to Mira (mirainsight), not for commercial use.

| File | Background | Size |
| --- | --- | --- |
| `moon.jpg` | Your photo: a blurred dusk sky with a small moon | 1080 x 1928 (tall: it drifts up 24px on each slide, so a set reads as one strip) |
| `wind2-soft.jpg` | Path (soft): a glowing orange winding path on deep red-brown | 1080 x 1350 |
| `wind2-faint.jpg` | Path (faint) | 1080 x 1350 |
| `hand-soft.jpg` | Hand (soft): a glowing open hand on deep red-brown | 1080 x 1350 |
| `hand-faint.jpg` | Hand (faint) | 1080 x 1350 |

The generated backgrounds (Glow, Streaks, Paper, Flat) need no files.

# Doodles

Sleep Tight is built with a set of 16 hand-drawn-style stars and sparkles on transparent backgrounds. They are **not bundled in this public repo**: they came from Canva's element library, whose content licence does not allow redistributing the artwork on its own.

The look still works without them. The example pages load them from this folder and simply show no stars when the files are missing.

To see the full look, drop your own transparent PNGs in here with these names (any star or sparkle art will do):

`smiley-yellow`, `crayon-yellow`, `chalk-gold`, `chalk-terracotta`, `glitter-gold`, `eyes-orange`, `outline-smiley`, `scribble-a`, `scribble-b`, `scribble-c`, `flat-cream`, `outline-red` (stars), and `asterisk-coral`, `plus-black`, `flat-blue`, `flat-orange` (sparkles). Each as `<name>.png`.

Tip: key out the white background first, so the doodle can sit on the stripes and the cream card.
